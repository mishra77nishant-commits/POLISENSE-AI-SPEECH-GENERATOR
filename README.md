# POLISENSE AI Speech Generator

An AI-powered web application that generates structured speeches based on the user's topic, audience, language, and speech preferences.

## Live Demo

**Try the application:** https://polisense-ai-speech-generator.vercel.app/

## Features

- AI-powered speech generation
- Multiple speech templates
- Custom speech topics and target audiences
- Language selection
- Copy generated speeches
- Download speeches as TXT and PDF
- React-based user interface
- FastAPI backend integration

## Technology Stack

**Frontend**
- React
- Vite
- JavaScript
- CSS

**Backend**
- Python
- FastAPI
- REST API

**AI Integration**
- Groq API

**Deployment**
- Vercel (Frontend)
